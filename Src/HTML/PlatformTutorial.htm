框架教程--Platform对象
说明：Platform全局单例对象是提供跨平台方面的功能，不同平台有不同的功能和表现；QML中使用$Platform来获取使用，Qt插件中使用 qApp->property("$Platform").value() 来获取使用。 一、SysInfo 类（封装 QSysInfo，全平台通用） 1. 属性（Q_PROPERTY） 属性 类型 说明 sizes int 字长（WordSize），32位平台返回32，64位平台返回64 buildCpuArchitecture QString 编译时的CPU架构 currentCpuArchitecture QString 运行时的CPU架构（安卓下返回 arm64-v8a、armeabi-v7a 等相关字符串） buildAbi QString 编译时的ABI架构 kernelType QString 内核类型（如 winnt、linux、darwin） kernelVersion QString 内核版本号 productType QString 产品类型（如 windows、android、macos） productVersion QString 产品版本号 prettyProductName QString 产品美观名称 machineHostName QString 主机名 machineUniqueId QByteArray 机器唯一ID bootUniqueId QByteArray 本次启动的唯一ID 2. 槽函数（全部为 static，全平台通用） 命令：static int sl_sizes(); 功能：获取系统字长； 参数：无； 返回：字长位数（32或64）。 命令：static QString sl_buildCpuArchitecture(); 功能：获取编译时的CPU架构； 参数：无； 返回：架构字符串（如 x86_64、arm64）。 命令：static QString sl_currentCpuArchitecture(); 功能：获取运行时的CPU架构； 参数：无； 返回：架构字符串（安卓下返回 arm64-v8a 和 armeabi-v7a 相关字符串）； 注意：安卓下返回值与编译时架构的写法不同。 命令：static QString sl_buildAbi(); 功能：获取编译时的ABI架构信息； 参数：无； 返回：ABI字符串（如 x86_64-little_endian-llp64）。 命令：static QString sl_kernelType(); 功能：获取操作系统内核类型； 参数：无； 返回：内核类型字符串（winnt / linux / darwin 等）。 命令：static QString sl_kernelVersion(); 功能：获取操作系统内核版本； 参数：无； 返回：版本号字符串。 命令：static QString sl_productType(); 功能：获取产品（操作系统）类型； 参数：无； 返回：类型字符串（windows / android / macos 等）。 命令：static QString sl_productVersion(); 功能：获取产品（操作系统）版本号； 参数：无； 返回：版本号字符串。 命令：static QString sl_prettyProductName(); 功能：获取产品美观名称（包含类型+版本的组合描述）； 参数：无； 返回：描述字符串。 命令：static QString sl_machineHostName(); 功能：获取主机名； 参数：无； 返回：主机名字符串。 命令：static QByteArray sl_machineUniqueId(); 功能：获取本机唯一ID； 参数：无； 返回：唯一ID字节数组； 注意：部分平台可能返回空。 命令：static QByteArray sl_bootUniqueId(); 功能：获取本次开机（boot）的唯一ID； 参数：无； 返回：唯一ID字节数组； 注意：部分平台可能返回空。 二、_Platform 类 1. 通用属性（COMMON_PLATFORM_PROPERTIES，全平台通用） 属性 类型 读写 通知信号 说明 sysInfo SysInfo* 只读（CONSTANT） 无 返回 SysInfo 单例 compileType QString 只读（CONSTANT） 无 编译类型（Debug/Release等）？？？ libType int 只读（CONSTANT） 无 库类型（B/L/S静态或动态）？？？ dynamicLibrarySuffixName QString 只读（CONSTANT） 无 动态库后缀名（dll / so 等） separator QChar 只读（CONSTANT） 无 路径分隔符（win为’\‘，unix为’/'） listSeparator QChar 只读（CONSTANT） 无 路径列表分隔符（win为’;‘，unix为’:'） readOnlyPath QString 只读（CONSTANT） 无 只读路径（资源目录） readWritePath QString 只读（CONSTANT） 无 可读写路径 resourcePath QString 只读（CONSTANT） 无 资源路径 externalDataPath QString 读写 externalDataPathChanged 外部数据目录（绝对路径） logPath QString 读写 logPathChanged 日志目录（绝对路径） 2. 通用信号（COMMON_PLATFORM_SIGNALS，全平台通用） 命令：void externalDataPathChanged(const QString& newData);
