框架教程--Frame对象
说明：Frame全局单例对象是提供框架底层方面的功能（文件、网络、服务、进程、线程、数据库、缓存、编码转换、加解密、压缩解压等），有众多的API槽函数和信号；QML中使用$Frame或FrameManager来获取使用，Qt插件中使用 qApp->property('$Frame').value() 来获取使用。 一、L_LibraryWrapper 类 命令：QVariant sl_runQtFunction(const QString& funtionName, const QVariant& args); 功能：运行动态库中的Qt函数； 参数：funtionName为函数名；args为传给函数的QVariant参数； 返回：QVariant类型，函数返回值；失败返回空QVariant()； 注意：动态库函数签名须为 QVariant 函数名(QVariant)；调用失败会输出警告并返回QVariant()。 命令：QVariant sl_runFunction(const QString& funtionName, const QString& args); 功能：运行动态库中的普通函数； 参数：funtionName为函数名；args为传给函数的字符串参数； 返回：QVariant类型（实际为QString），函数返回值；失败返回空QVariant()； 注意：动态库函数签名须为 char* 函数名(const char*)，参数需函数内部自己处理。 二、PreciseTimerThread 类（精确定时器，占用一个线程死循环）：继承自QThread，单例类，使用：$Frame.preciseTimer； 属性：int interval：当前定时器间隔时间； 信号：void sg_triggered(qint64 timestamp); 功能：定时器每达到设定间隔时触发（按毫秒时间戳）； 参数：timestamp为当前毫秒时间戳； 示例：$Frame.preciseTimer.sg_triggered.connect(function(interval){console.warn(interval)}); 注意：需先调用 sl_start() 启动。 命令：bool sl_start(int interval = 16, QThread::Priority priority = QThread::InheritPriority); 功能：启动定时器线程； 参数：interval为定时间隔（毫秒，最小为1）；priority为线程优先级； 返回：bool类型，true成功；已在运行则返回false。 示例：$Frame.preciseTimer.sl_start(16); 命令：bool sl_stop(); 功能：停止定时器线程； 返回：bool类型，true成功；未运行则返回false； 示例：$Frame.preciseTimer.sl_stop(); 功能：给QML发送信号（队列方式）； 参数：v为传递的数据； 信号：void sg_newArgs(const QStringList& args); 功能：打开新程序（多开）时传递的参数（新应用关闭，原应用发送此信号）；框架会默认处理； 参数：args为参数列表； （一）配置功能（键值对） 命令：int sl_localDBSaveConfig(const QString& key, const QString& value); 功能：存储数据key和value到本地加密数据库SQLITECIPHER； 参数：key为键；value为值； 返回：int类型，为0表示和原值相同，>0为修改条数，<0表示出错。 命令：int sl_localDBDeleteConfig(const QString& key); 功能：从本地加密数据库SQLITECIPHER中删除数据key； 参数：key为键； 返回：int类型，为0表示不存在key，>0为删除条数，<0表示出错。 命令：static int sl_insertConfig(const QString& k, const QVariant& v);
